# Intento2FabulosoReporte

Aqui voy a ir documentando lo que tenemos que hacer

Para esta version muy básica sólo necesitaremos crear 3 archivos:

1. Archivo de configuracion de Quarto que forzosamente se tiene que llamar " quarto.yml"
2. Archivo de Quarto (.qmd) donde pondremos el contenido de nuestro fabuloso reporte. Que mandatoriamente se debe llamar "index.qmd
3. Archivo de configuracion de una accion de GitHub para renderear nuestro

Adicionalmente "picaremos" unos botones aca en GitHub para la magia suceda

Paso1: Crear el archivo "_quarto.yml"
Paso 2: Crear el archivo "index.qmd"
Paso 3: Picar botones aquí en GitHub. Setting -> Pages -> GitHub Actions
